Functions I

Besides being a statistical software, R is a programming language.

Most R objects are functions. Indeed:

class(sum) # Identifies the type of object
[1] "function"
class(log) # Second example
[1] "function"

It is therefore possible to define new functions, in addition to the ones that already exist.

Once created, functions can be used exactly like all the others.

Functions II

To create a new function, one uses the command function.

The new function cube computes the cube of the number it receives as input:

cube <- function(x) {
  out <- x^3
  out
}

The last object (in this case called out) is returned as the result:

cube(4) # Computes the cube of the value 4
[1] 64

Alternatively, we can also use the command return to return the result:

cube <- function(x) {
  out <- x^3
  return(out) # Makes it explicit that the value to be returned is out
}
cube(8) # Computes the cube of the value 8
[1] 512

Functions III

It is possible to define new functions with multiple arguments, also choosing their default values

power <- function(x, p = 2) {
  out <- x^p
  out
}

The default value for the argument p is the square (p = 2), indeed:

power(x = 4) # Computes the square of the value 4
[1] 16
power(4) # Alternative syntax: the argument names need not be specified
[1] 16

However, we can select a different power as follows:

power(x = 4, p = 3) # Computes the cube of the value 4
[1] 64
power(4, 3) # Alternative syntax: the argument names need not be specified
[1] 64

Control statements I

The control statement if makes it possible to perform a given operation only if a certain condition is satisfied (TRUE or FALSE).

The (optional) control statement else makes it possible to perform an alternative operation if the previous condition is not satisfied.

For example, the following code prints on screen (function print) a different sentence depending on whether the condition is true or false:

condition <- pi^2 < 10 # Boolean value (in this case the condition is TRUE)

if (condition) {
  print("The condition is true")
  # Some commands to be executed
  # ...
} else {
  print("The condition is false")
  # Other commands to be executed
  # ...
}
[1] "The condition is true"

Control statements II

The following function square_root is a more concrete example concerning if and else.

If the number provided as input is negative, a NaN is returned:

square_root <- function(x) {
  if (x < 0) {
    # Warning message; it would actually be more appropriate to use "warning"
    print("The value of x must be positive")
    out <- NaN # Return Not A Number
  } else {
    out <- sqrt(x)
  }
  out
}

square_root(-2) # The condition x < 0 is satisfied
[1] "The value of x must be positive"
[1] NaN
square_root(36) # The condition x < 0 is NOT satisfied
[1] 6

while and for loops I

for loops and while loops repeat the operation contained between the curly brackets { } until a given condition is satisfied.

Let us start with a simple example concerning the while function:

i <- 5 # We start with i = 5

while (i <= 25) { # Repeats the operation as long as i is smaller or equal to 25
  print(i) # Prints on screen the value of i
  i <- i + 5 # Increases the value of i

  # In real settings, here there are of course other operations to be executed
  # ...
}
[1] 5
[1] 10
[1] 15
[1] 20
[1] 25

while and for loops II

Be careful not to create endless loops!

The following code requires a forced interruption of the R session or, in the worst case, a restart of the computer:

# DO NOT RUN THE FOLLOWING CODE!
#
# The condition i <= 25 is always true because i is never updated
i <- 5
while (i <= 25) {
  print(i)

  # Other operations to be executed
  # ...
}

while and for loops III

As an alternative to while loops, one can use the more explicit syntax of for loops.

The for loop executes the content of the curly brackets considering, one at a time, the values contained for instance in a vector:

values <- seq(from = 5, to = 25, by = 5)
values
[1]  5 10 15 20 25
for (i in values) {
  print(i + 2) # Prints on screen the value of i + 2

  # Other operations to be executed
  # ...
}
[1] 7
[1] 12
[1] 17
[1] 22
[1] 27

Summary exercise I

Compute the elements of a square matrix {\bf D} of dimension n \times n, whose elements are equal to d_{ij} = (x_i - x_j)^2, \qquad i,j \in \{1,\dots,n\}, where {\bf x} = (x_1,\dots,x_n)^\intercal is a generic vector in \mathbb{R}^n.

In other words, define a function distances(x) that, starting from a generic vector x, returns a matrix D.

Outline of the solution

First create a matrix D whose elements are all equal to 0, using the command matrix.

Then use two “nested” for loops, that is one inside the other, to compute each of the values D[i, j].

Solution of summary exercise I

distances <- function(x) {
  n <- length(x) # Get the length of the vector x
  D <- matrix(0, nrow = n, ncol = n) # Creation of an empty matrix

  for (i in 1:n) {
    for (j in 1:n) {
      D[i, j] <- (x[i] - x[j])^2
    }
  }
  D # Value to be returned
}

x <- c(5, 2, 1, 24) # Example to check that it is correct
distances(x)
     [,1] [,2] [,3] [,4]
[1,]    0    9   16  361
[2,]    9    0    1  484
[3,]   16    1    0  529
[4,]  361  484  529    0
Note

There are many different (but correct) ways of implementing this function. Incidentally, this solution is by no means the most efficient one.

Summary exercise II

Fizzbuzz is a simple programming exercise often used in job interviews to check basic programming skills.

The task is the following: for all the numbers from 1 to 100 print on screen:

  • the word fizz if the number is a multiple of 3,

  • the word buzz if it is a multiple of 5,

  • the word fizzbuzz if the number is a multiple of both 3 and 5,

  • the number itself otherwise.

Hint

Use the function print and the remainder function %% of R. Moreover, to make the code leaner it is possible to use the control statement called else if.

Solution of summary exercise II

The solution below makes use of the else if construct.

for (i in 1:100) {
  condA <- (i %% 3) == 0 # Is the number a multiple of 3?
  condB <- (i %% 5) == 0 # Is the number a multiple of 5?

  if (condA & condB) {
    print("fizzbuzz")
  } else if (condA) {
    print("fizz")
  } else if (condB) {
    print("buzz")
  } else {
    print(i)
  }
}

The *apply family of functions

When possible, it would be better to avoid using for loops, because they tend to be slow in R (unlike other languages, such as C++).

A more elegant alternative, although not necessarily a more efficient one, is the *apply family of functions, that is: apply, tapply, sapply, mapply, lapply.

The simplest one, apply, executes a given function for each row / column of a matrix.

Exercise

Consult the documentation of the *apply functions to get a first idea of how they work.

R packages

R is organised in packages.

If we want to use the functions of a package, it can be loaded using the function library, that is:

library(MASS) # Loads the MASS package into memory
library(knitr) # Loads the knitr package into memory

If a package is not available on the computer, it has to be installed.

One can use the following command, or use the “Packages” window available in RStudio.

install.packages("knitr") # Installs the knitr package
