Numerical computing and programming

Exercise A - Solution: function.R

Write in R the function f(x) associated with

f(x) = \frac{|\sin(\pi/(4 x^2))|}{x}, \qquad x \neq 0.

  1. What is the value of f(1)? And of f(10^8)?

  2. Approximate f(1) and f(10) to the first two decimal digits.

  3. Draw a plot of the function f(x) over the interval (1,3).

  4. Compute \sum_{k=1}^{K} f(k), for K = 500.

  5. Difficult. The integrate function of R (see the documentation) makes it possible to compute numerically integrals of the form I = \int_a^b f(x)\mathrm{d}x, where a < b are two real values. Compute the value of the integral \int_1^3 f(x)\mathrm{d}x, where f(x) is the function used in the previous points.

Exercise B - Solution: binomial.R

Verify numerically the following identities for n = 10, 100, 1000 (where possible).

  1. \sum_{k=0}^n(-1)^k\binom{n}{k} = 0.

  2. \sum_{k=1}^n k \binom{n}{k} = n 2^{n-1}.

  3. \sum_{k=1}^n(-1)^{k}k \binom{n}{k} = 0.

Exercise C - Solution: roots.R

Write in R a function roots(a, b, c) that takes as input the coefficients of the polynomial

a x^2 + b x + c, and returns the vector of the values of x that make it equal to zero.

  1. Compute roots(1, 5, 2);

  2. Compute roots(1, 2, 1);

  3. Compute roots(1, 1, 1) and comment on the result.

Exercise D - Solution: matrix.R

Define in R a symmetric matrix {\bf A} of dimension 5 \times 5, whose elements are {\bf A} = \begin{pmatrix} 26 & 22 & 17 & 22 & 23 \\ 22 & 18 & 14 & 23 & 27 \\ 17 & 14 & 14 & 20 & 24 \\ 22 & 23 & 20 & 26 & 23 \\ 23 & 27 & 24 & 23 & 12 \\ \end{pmatrix}.

  1. Verify empirically that \text{det}({\bf A}^{-1}) = 1 / \text{det}({\bf A}).

  2. Verify empirically that \text{det}({\bf A}^2) = \text{det}({\bf A})^2.

  3. Compute the trace of {\bf A}, that is \text{tr}({\bf A}) = \sum_{i=1}^n a_{ii}, for n = 5.

  4. Verify empirically that \text{det}({\bf A}) = \prod_{i=1}^n \lambda_i, where \lambda_1,\dots,\lambda_n are the eigenvalues of {\bf A}.

Exercise E - Solution: distances.R

The Euclidean distance between two vectors {\bf x} and {\bf y} in \mathbb{R}^p is defined as d({\bf x},{\bf y}) = \sqrt{\sum_{j=1}^p(x_j - y_j)^2}, whereas the Frobenius norm ||{\bf A}||_F of a real-valued matrix {\bf A} of dimension n \times m is defined as ||{\bf A}||_F = \sqrt{\sum_{i=1}^n \sum_{j=1}^m a_{ij}^2}.

  1. Write the R function dist_euclid(x, y) that computes the Euclidean distance between two vectors.

  2. If x = c(1, 4, 2, 2, 10) and y = c(8, 1, 8, 3, 6), what is the value of dist_euclid(x, y)?

  3. Write the R function frobenius_norm(A) that computes the Frobenius norm of a matrix A.

  4. If A = cbind(1:5,6:10,11:15), what is the value of frobenius_norm(A)?

  5. Verify that dist_euclid(x, y) and frobenius_norm(x - y) return the same value. Why is that the case?

Exercise F - Solution: diagonal.R

Let {\bf A} be a matrix of dimension n \times n. Implement a function that extracts the diagonal elements a_{ii}, for i = 1,\dots,n, of the matrix {\bf A}. Then compare it with the diag function of R.

mtcars dataset - Solution: mtcars.R

Consider the dataset data(mtcars), which is available in R. Answer the following questions:

  1. How many rows and how many columns does this dataset have?

  2. Why does the command mtcars[1:20] return an error? What is the difference with the command mtcars[1:20, ]?

  3. Each of the following lines contains an error (a bug). Propose a modification to fix it

mtcars[mtcars$cyl = 4, ] 
mtcars[-1:4, ] 
mtcars[mtcars$cyl <= 5] 
mtcars[mtcars$cyl == 4 | 6, ]
Students dataset (AK 1.2(a)) - Solution: Students.R

The Students data file of Agresti and Kateri (2022) collects the answers of 60 social science graduate students of the University of Florida to a questionnaire. It is available at this link and contains, among others, the following variables:

  • gender, the gender of the student (1 = female, 0 = male);

  • age, the age in years;

  • hsgpa and cogpa, the high school and the college grade point average, on a four-point scale;

  • veg, whether the student is a vegetarian (1 = yes, 0 = no);

  • life, the belief in life after death (1 = yes, 2 = no, 3 = undecided).

  1. Import the data into R and store them in the object students. The read.table function accepts a web address in place of a file name, so there is no need to download the file first.

  2. How many rows and how many columns does students have? Which type does R assign to the variables? Are there missing values?

  3. Note that gender and life are qualitative variables, even though they are stored as numbers. Convert them into factor objects with meaningful labels, then obtain the frequency table of life.

  4. Extract the sub-data-frame containing the variables age, hsgpa and cogpa only.

  5. How many students are vegetarian? How many of them are older than 30?

  6. Add to students a new variable gpa_change, the difference between the college and the high school GPA. For how many students did the GPA improve?
