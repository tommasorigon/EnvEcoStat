Writing your own functions

Exercise A - Solution: variance.R

The sample variance of the data {\bf x} = (x_1,\dots,x_n) is defined as

\text{var}({\bf x}) = \frac{1}{n}\sum_{i=1}^n(x_i - \bar{x})^2, where \bar{x} is the sample mean. Note that \text{var}({\bf x}) admits the alternative representation

\text{var}({\bf x}) = \frac{1}{2 n^2} \sum_{i=1}^n \sum_{j = 1}^n (x_i - x_j)^2.

  1. Write a function var2(x) that computes the variance of {\bf x} using the definition.

  2. Write a function var3(x) that computes the variance of {\bf x} using the formula based on the distances between pairs of elements.

  3. Suppose that x = c(1, 4, 2, 2, 10). Check that the two functions var2(x) and var3(x) return the same result.

  4. Suppose now that x <- 1:3000. Do you notice any difference with respect to the previous point?

  5. Compare the functions var2 and var3 with the function var implemented in R, using the data of point 3. Why do the results differ, even if only slightly? Consult the documentation to answer.

Data analysis

elections dataset - Solution: elections.R

At this link the data of the 2016 municipal elections in the city of Milan are available. Each statistical unit is a single vote; the variable party reports the list the vote was cast for, and the variable district the borough (Municipio) in which it was cast.

  1. Load the data into memory.

  2. Which variables does the dataset elections contain? Of which type are they?

  3. Obtain the number of votes obtained by each party in the different districts of Milan.

  4. Obtain the number of votes obtained by each party and draw a plot of it. Obtain moreover the percentage of votes obtained by each party.

  5. Write the function Gini(x) that computes the Gini index for a qualitative variable. The Gini index is defined as G = 1 - \sum_{j=1}^k f_j^2, where f_1,\dots,f_k are the relative frequencies of the k categories.

  6. Write a function Gini_norm(x) that computes the normalised Gini index, that is G_\text{norm} = \frac{k}{k-1} G.

  7. Evaluate the fragmentation of the votes among the parties in the different districts using the normalised Gini index. Organise the results in a table and say which district is the most fragmented and which one is the most concentrated, that is the one in which the votes are polarised towards a few parties. Pay attention to the direction of the index: a Gini index close to 1 means that the votes are spread evenly across the parties.

Murder dataset (AK 1.17) - Solution: Murder.R

The Murder data file of Agresti and Kateri (2022), available at this link, reports the murder rate (number of murders per 100{,}000 inhabitants) of each of the 50 states of the U.S. and of the District of Columbia (DC), according to the FBI Uniform Crime Reports.

At first, leave the observation relative to DC aside.

  1. Import the data into R and create a second data frame, without the row relative to DC.

  2. Using the data without DC, find the mean and the standard deviation, and interpret their values.

  3. Still without DC, find the five-number summary and construct the corresponding boxplot. Interpret them.

  4. Include DC again. What is affected more by this outlier: the mean or the median? The range or the interquartile range? Why?

Houses dataset (AK 1.19–1.20) - Solution: Houses.R

The Houses data file of Agresti and Kateri (2022), available at this link, lists the selling price (price, in thousands of dollars), the size (size, in square feet), the tax bill (taxes, in dollars), the number of bedrooms (bedrooms) and of bathrooms (baths), and whether the house is new (new, 1 = yes, 0 = no) for 100 home sales in Gainesville, Florida.

  1. Import the data into R. The read.table function accepts a web address in place of a file name, so there is no need to download the file first. Construct a frequency distribution and a histogram of price, and describe the shape of the distribution.

  2. Find the percentage of observations that fall within one standard deviation of the mean, that is in the interval (\bar{x} - s, \bar{x} + s). Why is this percentage not close to 68\%?

  3. Construct a boxplot of price and interpret it.

  4. Repeat the three previous points on the logarithm of the price. Does the empirical rule work better on this scale? Why?

  5. Use descriptive statistics to compare the selling prices of new and old houses. Would you regard this comparison as reliable?

  6. Let now y = price and x = size. Construct a scatterplot and interpret it. Identify the observation that seems to fall apart from the others.

  7. Find the correlation and interpret it. Then find the regression line, interpret the slope, and find the predicted selling price for a house of

    1. 1000 square feet, (ii) 4000 square feet.

  8. Remove the observation identified at point 6 and obtain the regression line again. How much do the estimates change?

UN dataset (AK 1.24) - Solution: UN.R

The UN data file of Agresti and Kateri (2022), available at this link, has United Nations data for 42 nations on the following variables:

  • GDP, the per capita gross domestic product, in thousands of dollars;

  • HDI, a human development index, with components referring to life expectancy at birth, educational attainment and income per capita;

  • GII, a gender inequality index, a composite measure reflecting inequality in achievement between women and men in reproductive health, empowerment and the labour market;

  • Fertility, the fertility rate, that is the number of births per woman;

  • CO2, the carbon dioxide emissions per capita, in metric tons;

  • Homicide, the homicide rate, per 100{,}000 people;

  • Prison, the prison population, per 100{,}000 people;

  • Internet, the percentage of people using the Internet.

  1. Import the data into R and conduct a descriptive analysis of the prison rates, highlighting any unusual observation.

  2. Construct the correlation matrix of the eight quantitative variables. Which pair has the strongest association?

  3. Study the association between CO2 and GDP through a scatterplot, the correlation and the regression line. Show how the predicted CO_2 varies as GDP goes from its minimum to its maximum value in this sample.

  4. The correlation between GDP and Prison is essentially zero. Does this mean that the two variables are unrelated? Look at the scatterplot, and then repeat the computation without the United States.

Sheep dataset (AK 1.27) - Solution: Sheep.R

A study of sheep analysed whether a sheep survived for a year from the original observation time (survival, 1 = yes, 0 = no) as a function of its weight, in kg, at the original observation. The Sheep data file of Agresti and Kateri (2022) is available at this link.

  1. Import the data into R. How many sheep are there? How many of them survived?

  2. Compare the weights of the sheep that survived with the weights of the sheep that did not, using numerical descriptive statistics.

  3. Compare the same two distributions graphically.

  4. Summarise the results of your analysis in a few sentences. Can you conclude that being heavier causes a sheep to survive?
